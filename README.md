# FocusCabin 🏕️

> 個人沉浸式專注工作台 · 100% 瀏覽器本機 Web Audio 音訊合成 · 零外部網路依賴

FocusCabin 是一款專為工程師與創作者打造的單頁專注工作空間（SPA），整合了「12 軌環境音混音台」、「番茄鐘」與「今日 3 件事」清單。所有音效皆由瀏覽器原生 Web Audio API 即時運算合成，無需載入外部肥大 MP3 音訊檔，斷網亦可流暢使用。

---

## 🌟 核心功能特色

- **12 軌環境音混音台（Web Audio 原生合成）**：
  - 🌧️ **細雨霏霏 (Gentle Rain)**：輕柔雨滴落在屋簷與窗玻璃的舒緩聲。
  - 🔥 **壁爐柴火 (Campfire)**：劈啪作響的溫暖木柴燃燒聲與低頻共鳴。
  - 🍃 **林間清風 (Forest Wind)**：微風輕拂樹梢、起伏搖曳的自然流動感。
  - 🌊 **深海浪潮 (Ocean Waves)**：規律起伏拍打海岸的潮汐浪聲，安撫焦慮。
  - ⚡ **遠方雷鳴 (Distant Thunder)**：雲層深處低沉滾動的沉穩雷響，極具安全感。
  - 💧 **山澗溪流 (Mountain Stream)**：清澈歡快、潺潺流淌的山間活泉水流聲。
  - ☕ **街角咖啡 (Coffee Shop)**：低回模糊的環境背景音，營造自習咖啡館氛圍。
  - ⌨️ **機械鍵盤 (Mechanical Typing)**：清脆溫潤的客製化機械軸打字聲，進入心流。
  - 🌙 **夏夜蟲鳴 (Summer Crickets)**：靜謐夏夜庭院的微風與蟋蟀細碎鳴叫。
  - 🚂 **夜行列車 (Night Train)**：鐵軌低頻律動的節奏感，適合放鬆與沈浸思考。
  - 📻 **深層褐噪 (Brown Noise)**：比白噪音更低沉厚實的深頻音，阻絕外界雜訊。
  - ✨ **頌缽共振 (Zen Drone)**：純淨和諧的低頻共鳴音波，引導思緒深度入定。

- **8 大經典快速氛圍一鍵切換**：
  - ⛈️ **暴雨木屋**：雨聲 + 柴火 + 遠雷
  - 💻 **深夜編程**：機械鍵盤 + 褐噪 + 頌缽共振
  - 🌊 **海邊晨曦**：海浪 + 清風 + 頌缽
  - 🌌 **夏夜星空**：夏夜蟲鳴 + 清風 + 柴火
  - 🏞️ **高山幽谷**：山澗溪流 + 細雨 + 清風
  - ☕ **街角咖啡**：咖啡廳 + 細雨 + 機械鍵盤
  - 🚂 **夜行列車**：鐵軌律動 + 深層褐噪
  - 🧘 **深層冥想**：頌缽共振 + 褐噪 + 山澗溪流

- **極簡番茄鐘**：
  - 支援 25 分鐘專注、5 分鐘短休、15 分鐘長休模式切換。
  - SVG 環形進度條與 JetBrains Mono 等寬倒數顯示。
  - 倒數結束播放雙頻頌缽清鳴，並支援瀏覽器桌面通知。
  - 支援鍵盤快速鍵：按 `Space`（空白鍵）即可暫停／繼續計時。

- **今日 3 件事 (Three Daily Wins)**：
  - 貫徹「每天只做最重要的 3 件事」減法思維，自動持久化儲存至瀏覽器 LocalStorage。

- **極簡暗色沉浸介面**：
  - 支援一鍵進入全螢幕沉浸模式。
  - 動態粒子微塵背景畫布，營造靜心工作氛圍。

## 🚀 使用 Docker Compose 快速啟動

專案已內建最佳化的 Multi-stage Dockerfile 與 Nginx 靜態伺服器配置：

### 1. 啟動服務

進入專案目錄並執行：

```bash
cd /Users/yujuchen/www/focus-cabin
docker-compose up -d --build
```

### 2. 開啟瀏覽器

啟動成功後，打開瀏覽器造訪：

👉 **[http://localhost:3000](http://localhost:3000)**

*(若需指定其他連接埠，可透過環境變數傳入，例如：`PORT=8085 docker compose up -d`)*

### 3. 停止服務

```bash
docker compose down
```
